# AI Glasses Competitive Intelligence Dashboard

一项结合产品研究、信息架构、数据可视化与前端开发的交互式 Web 项目。

> 将分散的海外 AI 眼镜竞品资料转化为可浏览、可筛选、可比较的研究工具，让读者既能快速获得结论，也能回到具体产品和来源核查依据。

## 项目背景

海外 AI 眼镜涵盖无屏拍摄、音频助手、轻量 HUD、AI+AR 与企业显示等多种形态。同一品牌还可能同时包含产品线、镜框款式与配件。传统长报告能够保存细节，却不便快速回答以下问题：

- 哪些产品有显示或摄像头？
- 同一品牌正在布局哪些产品路线？
- 几款候选产品在价格、硬件、交互和使用场景上有什么差异？
- 一个市场判断具体对应哪些产品和公开资料？

因此，本项目先统一研究对象和字段，再根据读者任务设计交互界面。

## 项目范围

- 9 个品牌组
- 19 个产品或产品线条目，不等同于 19 个独立 SKU
- 19 个横向比较维度
- 4 个研究视图：结论、目录、比较和图谱
- 官方资料优先，补充零售、媒体和公开社区入口

## 工作方法

```mermaid
flowchart LR
    A[定义研究问题] --> B[收集公开资料]
    B --> C[统一对象与字段]
    C --> D[建立结构化数据]
    D --> E[设计阅读路径]
    E --> F[实现交互界面]
    F --> G[检查并交付]
```

1. **定义研究问题**：先区分不同硬件形态解决的任务，而不是直接排列参数。
2. **整理公开资料**：以品牌官网为主，补充零售、媒体和社区入口，并保留证据边界。
3. **统一数据口径**：拆开品牌、产品线、款式和配件，避免把不同层级直接累计。
4. **设计信息架构**：分别承接看结论、找产品、做比较和理解市场分布四种任务。
5. **实现数据驱动界面**：让同一份产品数据生成目录、详情、比较表和图谱。
6. **检查交付完整性**：核对图片资源、缺失字段、展示标签与构建产物。

## 核心功能

### 1. 结论先行

通过市场信号、四类产品路线、用户反馈和典型场景建立全局认知。

### 2. 产品大观

支持品牌选择、关键词搜索、显示形态和摄像头组合筛选；点击产品可查看规格、款式、配件、优劣势、公开反馈和来源入口。

### 3. 横向对标

最多选择 4 个产品进入 19 维比较矩阵，并可突出存在差异的字段。

### 4. 象限图谱

从售价、资料中可确认的重量以及“显示 × 摄像头”组合观察不同产品路线。

## 为什么选择 HTML / Web 交付

用户研究、竞品研究和行业分析不一定只能以 PDF 或幻灯片交付。当资料包含大量对象、维度和比较关系时，网页可以把线性阅读转化为按问题探索：

- 概要负责建立认知；
- 筛选负责缩小范围；
- 对比负责支持判断；
- 详情和来源负责保留证据与核查路径。

这种 Web 交付方式降低了访问门槛，同时保留研究信息的层次与核查路径。

## 项目贡献说明

项目核心工作包括研究框架、资料结构化、信息架构、交互逻辑和内容核验；前端采用 AI 辅助开发，并在迭代过程中持续调整组件、校正数据表达和检查交付结果。

这里展示的是研究与信息工具，不是 AI 眼镜固件，也没有调用眼镜设备或实时 AI 模型服务。

## 数据与内容边界

- 当前内容是阶段性公开资料快照，不是实时更新数据库。
- 产品价格、功能和市场信息可能随地区、版本和时间变化。
- 零售评分、媒体评价与销量属于不同证据，不能相互替代。
- 产品或场景图片仅用于研究说明；公开展示前应继续核查使用范围。
- 数据缺失时保持未知，不用默认数值伪装成已确认事实。
